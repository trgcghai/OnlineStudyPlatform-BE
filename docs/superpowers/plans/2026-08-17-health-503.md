# Health Endpoint 503 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make `GET /health` return HTTP 503 (with the existing payload) when any infra component is down, per card T0-03.

**Architecture:** `AppService.getHealth` already computes real per-component statuses; we wrap the existing payload in a `ServiceUnavailableException` when any of the four infra components (`postgresql`, `redis`, `mongodb`, `minio`) reports `DOWN`. The all-up path stays byte-identical, so the e2e spec needs no changes.

**Tech Stack:** NestJS 11, TypeScript, jest (unit colocated `*.spec.ts`, e2e in `test/`), ioredis, mongoose, typeorm, minio SDK.

```typescript
describe('AppService', () => {
  let dataSource: { query: jest.Mock };
  let redisClient: { ping: jest.Mock };
  let mongooseConnection: { db: { admin: jest.Mock } };
  let minioClient: { listBuckets: jest.Mock };
  let service: AppService;

  beforeEach(() => {
    dataSource = { query: jest.fn().mockResolvedValue([{ '?column?': 1 }]) };
    redisClient = { ping: jest.fn().mockResolvedValue('PONG') };
    mongooseConnection = {
      db: {
        admin: jest.fn().mockReturnValue({
          command: jest.fn().mockResolvedValue({ ok: 1 }),
        }),
      },
    };
    minioClient = { listBuckets: jest.fn().mockResolvedValue([]) };

    service = new AppService(
      dataSource as unknown as DataSource,
      redisClient as unknown as Redis,
      mongooseConnection as unknown as Connection,
      minioClient as unknown as Minio.Client,
    );
  });

  it('reports all five components UP when every dependency is reachable', async () => {
    const health = await service.getHealth();

    expect(health.components.application.status).toBe('UP');
    expect(health.components.postgresql.status).toBe('UP');
    expect(health.components.redis.status).toBe('UP');
    expect(health.components.mongodb.status).toBe('UP');
    expect(health.components.minio.status).toBe('UP');
  });

  it('throws ServiceUnavailableException carrying the payload when minio is down', async () => {
    minioClient.listBuckets.mockRejectedValue(new Error('connection refused'));

    await expect(service.getHealth()).rejects.toBeInstanceOf(
      ServiceUnavailableException,
    );

    const error = await service.getHealth().catch((e: unknown) => e);
    const payload = (error as ServiceUnavailableException).getResponse() as {
      components: Record<string, ComponentHealth>;
    };
    expect(payload.components.application.status).toBe('UP');
    expect(payload.components.minio.status).toBe('DOWN');
    expect(payload.components.minio.details?.error).toBe('connection refused');
  });
});
```

**Note (review fix):** the original plan draft used `fail('getHealth should have thrown')` inside a try/catch — `fail` is not a global in Jest 30 (jest-circus), which produced a misleading `ReferenceError` failure and would mask regressions. The version above uses `.rejects` matchers instead. Also runs clean through Prettier (verify with `pnpm prettier --check src/app.service.spec.ts` or just run `pnpm lint` before committing).

- [ ] **Step 3: Implement the hardening in `src/app.service.ts`**

Replace every method from `async getHealth()` through the end of the class (`checkMinio`'s closing brace) with:

```typescript
  async getHealth() {
    const [postgresql, redis, mongodb, minio] = await Promise.all([
      this.checkPostgres(),
      this.checkRedis(),
      this.checkMongo(),
      this.checkMinio(),
    ]);

    const payload = {
      components: {
        application: { status: 'UP' },
        postgresql,
        redis,
        mongodb,
        minio,
      },
    };

    const infraDown = [postgresql, redis, mongodb, minio].some(
      (component) => component.status !== 'UP',
    );

    if (infraDown) {
      throw new ServiceUnavailableException(payload);
    }

    return payload;
  }

  private readonly HEALTH_CHECK_TIMEOUT_MS = 3000;

  private async check(
    name: string,
    run: () => Promise<unknown>,
  ): Promise<ComponentHealth> {
    let timer: ReturnType<typeof setTimeout> | undefined;
    const timeout = new Promise<never>((_, reject) => {
      timer = setTimeout(
        () => reject(new Error(`${name} health check timed out`)),
        this.HEALTH_CHECK_TIMEOUT_MS,
      );
    });

    try {
      await Promise.race([run(), timeout]);
      return { status: 'UP' };
    } catch (error) {
      return {
        status: 'DOWN',
        details: {
          error: error instanceof Error ? error.message : String(error),
        },
      };
    } finally {
      if (timer) {
        clearTimeout(timer);
      }
    }
  }

  private checkPostgres(): Promise<ComponentHealth> {
    return this.check('postgresql', () => this.dataSource.query('SELECT 1'));
  }

  private checkRedis(): Promise<ComponentHealth> {
    if (this.redisClient.status !== 'ready') {
      return Promise.resolve({
        status: 'DOWN',
        details: {
          error: `redis not connected (status: ${this.redisClient.status})`,
        },
      });
    }
    return this.check('redis', () => this.redisClient.ping());
  }

  private checkMongo(): Promise<ComponentHealth> {
    if (this.mongooseConnection.readyState !== 1) {
      return Promise.resolve({
        status: 'DOWN',
        details: {
          error: `mongodb not connected (readyState: ${this.mongooseConnection.readyState})`,
        },
      });
    }
    return this.check('mongodb', () =>
      this.mongooseConnection.db?.admin().command({ ping: 1 }),
    );
  }

  private checkMinio(): Promise<ComponentHealth> {
    return this.check('minio', () => this.minioClient.listBuckets());
  }
}
```

Keep the `ComponentHealth` interface and `getHealth()`'s contract unchanged (payload shape + 503 semantics identical).

(Implementation corrections verified in review: mongo short-circuit compares `readyState !== ConnectionStates.connected` — imported from 'mongoose' — because eslint `no-unsafe-enum-comparison` rejects comparisons to the magic number `1`; the mongo ping runner is wrapped `async () => await this.mongooseConnection.db?.admin().command({ ping: 1 })` to satisfy `Promise<unknown>` typing.)
